## Tone Guidelines

- **Professional but not corporate.** Write like a smart coworker, not a marketing department.
- **Specific, not vague.** Always reference actual dollar amounts and tool names.
- **Honest.** If there's nothing to optimize, say so. Trust > conversion.
- **Action-oriented.** Every section ends with a clear next step.
- **Technical audience.** Don't over-explain AI tools — the audience already uses them.
